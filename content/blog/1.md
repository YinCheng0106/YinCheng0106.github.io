## 前言
其實我一直想要做屬於自己的一個 **個人網站** 跟 **部落格**，在最初剛接觸前端的時候還有做一個非常陽春的個人網站(或者說是YINLA的官網:)，後面也有把網站推送到 Github Page **[點這邊](https://yincheng0106.github.io/)**，再加上之前就有接觸到前端框架 **[Vue](https://vuejs.org/)**，所以對 **Vue** 略懂一些。

因為對 **Vue** 相對 **React** 我比較熟悉，這次挑選了 **[Nuxt](https://nuxt.com/)** 當作我的框架。


### 先來簡單的介紹一下 **[Nuxt](https://nuxt.com/)**
**Nuxt** 是一個基於 **Vue.js** 的高層級框架，專為構建現代化的 Web 應用程式而設計。它提供強大的功能和預設配置，讓開發者能快速構建伺服器端渲染（SSR）、靜態網站生成（SSG）或用於單頁應用（SPA）的專案。

## 起飛
剛好趁著寒假這段期間，來學習與實作

### 規劃
#### 首先我的網頁主要的部分分為以下幾點：
- **首頁**：主要放我的主要 GitHub Repos，還有一些導覽欄
- **關於**：簡單描述網站架構以及開發本網站的工程師 (其實就是我啦:)
- **部落格**：利用 MarkDown 就可以編寫的文章以及文章清單
- **深淺模式**：希望自己跟瀏覽者不要眼睛瞎掉 (應該是現在網頁的標配吧:)
